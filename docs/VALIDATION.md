# 验证与验收

自动验证包括：从 Windows 移植的 34 个协议场景和新增的 2 个恢复场景，以及离线队列、账号隔离、目录合并、冲突、取消、SQLite 重开、缓存保护、递归下载、稳定快照、流式下载与引擎管道测试。

preview.2 新增目录预加载、独立展开、真实大小缓存失效、上传/校验期间浏览与连接并发、账号切换取消，以及校验开关持久化、费用网络策略、前台传输抢占、依赖任务和备份保留测试。

Mac 应用的 `--ui-selftest --output <json>` 在独立临时目录使用演示服务，检查原生窗口、侧栏和列表数据、经管道提交的目录任务，以及引擎和应用退出。默认尺寸和最小尺寸下均检查系统红黄绿按钮可见且不与内容重叠、文件操作工具栏完整保留，并导出包含标题栏的 PNG 与记录窗口几何信息的 JSON。Windows 使用引擎的 `--smoke-test`，不声称验证 Mac 原生界面。

`--platform-selftest --output <json>` 使用随机测试键检查凭据读写删除，并验证文件快照。Mac 运行真实 Keychain / NSFileCoordinator 桥接，Windows 运行独立 DPAPI 适配。不会读真实账号。

GitHub Actions 的绿色结果只表示对应提交通过所列检查。构建产物为 self-contained arm64 `.app`，包含原生桥接和 SQLite；包结构、代码签名及启动自检进入 CI。主仓库使用固定的预览签名证书，外部构建可回退为 ad-hoc 签名。

原生自检另外导出设置页、关于页截图，并检查随包提供的许可声明。打包同时生成 ZIP 和 DMG；DMG 会经 `hdiutil verify`、只读挂载、应用内容比对及签名复查，并检查 Applications 链接。

DMG 采用固定的 Finder 图标视图：左侧应用、右侧 Applications，中间箭头，缩小的安装说明图标位于箭头下方，不放置大标题。背景包含 1× / 2× 表示；打包工具通过隔离的 Python venv 安装固定版本并校验哈希的 `ds_store` / `mac_alias`，仅用于生成布局，不随应用分发。压缩后重新只读挂载，检查 `.DS_Store` 中的位置、窗口尺寸、背景引用与说明文件的自定义图标资源。CI 还打开最终镜像的真实 Finder 窗口并导出 `ui-dmg-macos.png`，用于人工查看；这不代替实机拖入 Applications 安装验收。

主仓库签名构建另在全新的 Mac runner 运行钥匙串跨进程回归；该机器不接收签名私钥、不导入预览证书，并验证证书不受系统信任。禁用系统授权交互，写入随机测试条目，以全新引擎进程读取两次；同一证书/标识但不同 CodeDirectory 哈希的引擎仍会遇到授权要求，测试明确保留这一限制。随后只重建合成测试条目，验证新版本自身多次启动可继续读取并删除；这不等价于真实旧条目的“始终允许”授权迁移。CI 不会读取已有账号凭据。外部分支缺少签名 Secrets 时跳过此项，不能将跳过结果视作更新授权验收。

钥匙串回归同时覆盖旧服务条目迁移到 `credentials.v2`，以及合成旧条目移除后新条目仍能读取。真实旧 ad-hoc 条目的首次授权弹窗仍需用户机器验收。

侧栏自检检查驱动器保留可折叠节点；驱动器和目录初始折叠。收藏栏自检覆盖默认展开、收藏与折叠状态持久化、账号隔离、移除、失效目录保留，以及通过既有 `browse` 导航到收藏目录；导出展开和收起截图。收藏只保存本地目录引用，列目录仍由引擎持有目录上下文锁，使用 diskid/folderid 与权限探测的原有请求顺序。

原生浏览交互自检使用两个顶层驱动器分组（保留冒号）、嵌套容器、重叠的 typeid/diskid 和 10,000 个目录。直接向 AppKit 控件派发鼠标按下/释放事件，验证披露箭头、单击选择、⌘ 多选、Shift 连选、连续点击、快速展开折叠，以及后台目录更新后的折叠和选择保持；另检查单击目录后松开鼠标时高亮保持在新目录、不回闪旧位置，导航失败时恢复到当前目录，以及收藏跳转后的祖先展开及选中定位。输出 `ui-macos-interaction.png`。这些事件测试不覆盖真实触控板、拖选及真实内网大目录端到端耗时。

驱动器卡顿回归另在 10,000 个后代节点已经展开时点击顶层驱动器的披露箭头，同时通过真实换行 JSON 解析器输入拆分的数据帧，模拟持续目录预加载。检查更新期间没有整树 reload、展开状态保留、最后状态与命令回复未丢失，以及后台准备的索引没有在主线程重建；另检查合并事件仍保持进度、最终状态、命令回复的顺序，避免旧进度覆盖完成状态。输出 `ui-macos.performance.json`，记录单次展开/收起的最大耗时与主事件循环的最大间隔；两项回归阈值均为 500 ms，报告保留具体值。这仍不能代表用户机器与真实目录的耗时。

尚需独立实机验收：

- macOS 14 实机运行；macos-15 runner 不能证明 14 的兼容性。
- Keychain 首次授权、取消授权、重登录和升级后访问。
- Word/Excel/PowerPoint 的保存、原子替换、连续保存和关闭文档行为。
- Finder 定位、拖放、系统文件选择器、Dock 重开、菜单栏、睡眠唤醒与退出。
- 真实服务器登录、权限、目录合并、上传/覆盖、冲突处理及断网恢复；只在明确指定的测试目录执行。
- 下载产物在另一台 Mac 的首次启动与 Gatekeeper 交互；预览包尚未公证。

真实服务器请求、人工验收和签名公证不能用模拟测试替代。未满足以上关卡前保持预览状态。
