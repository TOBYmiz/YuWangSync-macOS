# 验证与验收

## 自动验证

- 移植的 34 个协议场景与 2 个恢复场景。
- 离线队列、账号隔离、目录合并、冲突、取消、SQLite 重开、缓存保护、递归下载、稳定快照、流式下载、引擎管道。
- preview.2 新增：按需目录枚举、独立展开、真实大小缓存失效、上传/校验期间并发浏览与连接、账号切换取消、校验开关持久化、费用网络策略、前台传输抢占、依赖任务、备份保留。

## 自检

`--ui-selftest --output <json>`：在独立临时目录用演示服务检查原生窗口、侧栏与列表数据、经管道提交的目录任务、引擎与应用退出；默认和最小尺寸下检查红黄绿按钮可见不重叠、文件操作工具栏完整；导出含标题栏的 PNG 和窗口几何 JSON。

`--platform-selftest --output <json>`：用随机测试键检查凭据读写删除与文件快照。Mac 运行真实 Keychain / NSFileCoordinator 桥接，Windows 运行 DPAPI 适配。不读真实账号。

## 打包与签名检查

CI 检查 self-contained arm64 `.app` 的结构、代码签名和启动。主仓库使用固定预览签名证书，外部构建回退 ad-hoc。打包生成 ZIP 和 DMG；DMG 经 `hdiutil verify`、只读挂载、内容比对、签名复查及 Applications 链接检查。

DMG 使用固定 Finder 图标视图（左应用、右 Applications、中间箭头、箭头下缩小说明图标，无大标题），背景含 1× / 2× 表示。打包工具通过隔离 venv 安装固定版本并校验哈希的 `ds_store` / `mac_alias`，仅用于布局，不随应用分发。压缩后重新只读挂载，检查 `.DS_Store` 中的位置、窗口尺寸、背景引用和说明文件图标资源。CI 打开最终镜像的 Finder 窗口导出 `ui-dmg-macos.png` 供人工查看，不代替实机拖入安装验收。

主仓库签名构建另在全新 Mac runner 运行钥匙串跨进程回归：不接收签名私钥、不导入预览证书，验证证书不受系统信任；禁用系统授权交互，写入随机测试条目，由全新引擎进程读取两次；不同 CodeDirectory 哈希的同证书引擎仍需授权，测试保留该限制；随后重建合成条目，验证新版本多次启动可读取并删除。该测试不等价于真实旧条目的“始终允许”授权迁移。CI 不读取已有账号凭据；外部分支缺签名 Secrets 时跳过，跳过不等于通过。回归同时覆盖旧服务条目迁移到 `credentials.v2`。

## 原生交互与性能自检

侧栏自检：驱动器保留可折叠节点；驱动器和目录初始折叠；收藏栏默认展开，收藏与折叠状态持久化，收藏区与目录树分隔高度默认值与持久化，账号隔离，移除，失效目录保留，通过既有 `browse` 导航到收藏目录并重列一层。启动时先显示持久化的目录树、子项和权限结果，再低优先级后台刷新共享盘树及根目录，用户开始导航时取消。当前目录每次进入重列一次并持久化；其他已列目录复用缓存，仅首次展开未列过的目录时加载下一层；不启动整树预加载。权限结果独立持久化，当前目录重列不重复探测；强制刷新和写任务前重新确认。权限探测请求由引擎按 diskid/folderid 顺序持有目录上下文锁执行。

浏览交互自检：两个顶层驱动器分组（保留冒号）、嵌套容器、重叠 typeid/diskid、10,000 个目录。向 AppKit 控件派发鼠标按下/释放事件，验证披露箭头、单击选择、⌘ 多选、Shift 连选、连续点击、快速展开折叠、后台更新后的折叠与选择保持；检查单击目录松开后高亮不回闪、导航失败恢复当前目录、收藏跳转后祖先展开与选中定位。输出 `ui-macos-interaction.png`。不覆盖真实触控板、拖选及真实内网大目录耗时。

卡顿回归：10,000 个后代节点已展开时点击顶层驱动器披露箭头，同时用真实换行 JSON 解析器输入拆分数据帧。检查更新期间无整树 reload、展开状态保留、最终状态与命令回复未丢失、后台索引不在主线程重建；合并事件保持进度、最终状态、命令回复顺序。输出 `ui-macos.performance.json`，记录单次展开/收起最大耗时与主事件循环最大间隔，阈值均为 500 ms。不代表用户机器与真实目录耗时。

## 尚需实机验收

- macOS 14 实机运行。
- Keychain 首次授权、取消授权、重登录、升级后访问。
- Word / Excel / PowerPoint 的保存、原子替换、连续保存、关闭文档。
- 系统文件选择器、Dock 重开、菜单栏、睡眠唤醒、退出。
- 目录合并、上传/覆盖、冲突处理、断网恢复。
- 下载产物在另一台 Mac 的首次启动与 Gatekeeper 交互；预览包未公证。
