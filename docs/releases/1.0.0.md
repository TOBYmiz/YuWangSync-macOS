# YuWangSync macOS 1.0.0

首次公开发行，适用于 macOS 14 或更高版本的 Apple Silicon Mac。应用包含独立运行时，可通过 DMG 拖入 Applications 安装，也可从 ZIP 中解压 `.app`。

## 更新内容

- 原生文件浏览、收藏、目录导航和离线文件管理。
- 上传队列支持冲突处理、断点恢复和结果校验；离线操作会在重新连接后继续。
- 数据库增加账号、任务和目录索引缓存，避免重复写入，并减少浏览目录时读取的记录范围。
- 浏览器目录列表的合并和批量数据库提交改为异步执行。
- ZIP 与 DMG 均附 SHA-256 校验文件。

## 安装与已知限制

- 应用使用仓库自签名证书，尚未使用 Apple Developer ID 签名或 Apple 公证。macOS 首次打开时可能显示 Gatekeeper 提示。
- macOS 14 真机、Office 编辑、Finder 拖放、其他 Mac 上的钥匙串授权及真实服务器写操作仍需独立验收。请保留重要文件备份；详情见 [验证清单](../VALIDATION.md)。
